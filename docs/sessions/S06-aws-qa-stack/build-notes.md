## What was built

**Go (Rahul reviews):**
- `internal/config/resolve.go` (new): `Resolve(ctx, getenv, aws)` returns a `getenv` that answers `DATABASE_URL`, `APP_URL` and `TOKEN_SECRET` from AWS when `DATABASE_URL_PARAM`, `APP_URL_PARAM` or `TOKEN_SECRET_ARN` names them. Locally nothing is named and AWS is never called. Errors name the variable and the parameter, never a value. A value set both ways is refused.
- `internal/config/config.go`: `FORWARDED_HOPS` (0–4); on Lambda (`AWS_LAMBDA_FUNCTION_NAME` set) `CONFIG_STRICT=true` is required.
- `internal/serve/lambda.go` (new): `Lambda(handler, hops)` wraps the router with `algnhsa` for API Gateway payload v2 (cookies in, every `Set-Cookie` out as a list), and `clientAddr` sets `RemoteAddr` to the browser's address: the `hops`-th from the right of `X-Forwarded-For`, so addresses the browser sent itself are ignored; with too few addresses it keeps the connection's.
- `internal/serve/aws.go` (new): the real SSM and Secrets Manager clients, made on first use.
- `internal/serve/serve.go`: resolve → load → pool (Lambda settings) → `lambda.Start(Lambda(...))` on Lambda, else `ListenAndServe` (also through `clientAddr`).
- `internal/httpapi`: `GET /api/qa/client` (capture mode only, like the other QA routes, `no-store`): the address the rate limits count this caller by and the `X-Forwarded-For` the API got. Added to measure the proxies on QA and for testers to check it.
- `internal/httpapi`: the staff session cookie and both sign-outs are `Secure` when `APP_URL` is https (`secureCookies()`), as the patient's sign-in already was.

**CDK (Python, `infra/`):** see [infra/README.md](../../../infra/README.md). In short:
- `countries.py`: the only place a region, account, address or country default is written. Each entry is checked when made (locale must be `language-REGION`; `DEV_LOGIN` only in QA; etc.). `python countries.py uk-qa region` prints one value for the scripts.
- `ApiStack`: two Lambdas (`poised-uk-qa-staff-api`, `-patient-api`), explicit 14-day log groups, the CDK-generated token secret (deleted with the stack), IAM that reads only `/sj/qa/database-url` and `/sj/qa/app-url` plus the secret, and the HTTP API (`ANY /api/p/{proxy+}` → patient-api, `ANY /api/{proxy+}` → staff-api). The `Budget` construct sits here.
- `WebStack`: the Amplify app (no repository), branch `main` (no auto build), the two rules in order (`/api/<*>` → the HTTP API, 200; the SPA rule → `/index.html`, 200), and `/sj/qa/app-url`.
- `PoisedStage`: both stacks, Poised's own bootstrap qualifier, tags `poised-env=<env>` and `project=poised` on everything.
- `scripts/`: `lib.sh` (reads the entry, prints the profile and account, **refuses credentials for another account**), `aws-setup.sh`, `deploy-web.sh`, `db.sh`, `check-account.sh`.

**Make targets:** (every AWS one takes `PROFILE=<profile>`, which wins over `AWS_PROFILE` in `.env` or the shell; added 14 Oct after Rahul's `make aws-setup` picked up `.env`'s `sid-dev`) `build-lambdas`, `infra-test` (also part of `make test`), `synth`, `aws-setup`, `deploy-stacks`, `aws-db`, `deploy-web`, `deploy-qa`, `destroy-stacks`.

**TypeScript (Rahul: what changed and why):**
- `apps/web/src/lib/chunkError.ts`: `reloadOnce(storage, reload)` no longer has a 10-second window. It reloads only if its flag isn't already set, and `pageRendered(storage)` clears the flag. `sessionStore()` moved here from `RouteError.tsx`.
- `apps/web/src/pages/Root.tsx`: calls `pageRendered` once when it mounts. Root is replaced by the error screen when a page fails, so Root mounting means a page rendered.
- `apps/web/src/lib/config.ts`: `loadConfig` aborts `GET /api/config` after 5 seconds (an `AbortController` and a timer), so a hung API can't leave a blank page.

## Decided by the builder (automatic mode)

- **Poised's own CDK bootstrap** (qualifier `poised`, stack `poised-cdk-toolkit`), not the account's existing `CDKToolkit`: the conductor said never to modify or depend on another project's resources, and `cdk bootstrap` with a newer CLI would update the shared one. Checked: `CDKToolkit`'s last update is still 26 Aug 2024.
- **The web address comes from SSM (`/sj/qa/app-url`, written by WebStack)**, not an environment variable: an environment variable would make ApiStack → WebStack → ApiStack a cycle while the address is Amplify's own.
- **Budget:** $6/month (about £5; Budgets uses the account's billing currency, USD), counting only `poised-env=uk-qa`, alerts at 80% actual and 100% forecast. The address is in SSM (`/sj/alert-email`), not the repo; `make aws-setup` stores it from `ALERT_EMAIL`. The amount is `budget_usd` in `countries.py`.
- **`FORWARDED_HOPS = 3`** in `api_stack.py`, **measured on QA**: the header arrives as `<browser>, <CloudFront edge>, <Amplify's outbound address>`. With 2 (the first guess) `/api/qa/client` showed a CloudFront address; with 3 it shows the browser's, and a made-up first address sent by the browser is ignored.
- **Lambda timeout 25 s** (API Gateway stops at 30 s; a sleeping Neon database takes a few seconds to wake).
- **No throttling or reserved concurrency** beyond the defaults (plan F4; the README says why).
- **The CDK CLI is pinned in the Makefile** (`npx aws-cdk@2.1145.0`); Python packages are pinned in `infra/requirements.txt` (`aws-cdk-lib==2.273.0`, `constructs==10.8.1`, `pytest==9.1.1`). `infra/.venv` is made by `make` with `PYTHON` (default `python3.12`), as `e2e/.venv` is.
- **`make test` now also runs the CDK tests** (the plan: "run it in the synth step"; S07's synth step runs `make lint test`).
- **The audit CSV's 6 MB Lambda limit** (pending.md, S11) is left for S17: QA's data is small.
