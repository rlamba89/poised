# S21 answers

Asked by the conductor (`/run-sessions S18 S22`), 20 Oct 2026.

1. **Who is a task assigned to?** **(a) A team** from a fixed list: nurse, anaesthetist, admin (recommended). Anyone at the hospital may complete any task.
2. **Worklists:** **yes, the six fixed ones** (recommended): Ready for review; Not responding; Anaesthetic review needed; Procedure within N days and not Ready for admission; On hold; Open tasks.
3. **"Within N days":** **a hospital setting, default 14** (recommended).
4. **Status messages (EPI-08):** **yes** (recommended). Ready for admission and Cancelled, by text and email. Each template has a per-hospital on/off setting, **off by default**. `{{firstName}}` and `{{hospital}}`, with `{{link}}` optional.
