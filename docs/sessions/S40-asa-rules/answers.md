# S40 answers

Asked by the conductor in chat, 26 Oct 2026 (Rahul). Research behind the answers: [docs/research/c6-scores-asa.md](../../research/c6-scores-asa.md).

1. **A new version of an older questionnaire gets the default rules:** yes (shown on its Rules page, editable before publishing).
2. **A patient whose answers give no ASA grade** (fit and well): **a setting on each HQ** decides whether they can be auto-triaged, **on by default** (Rahul: "most of the time it will be auto-triaged, but some won't want that; HQ by HQ").
3. **Rules and the nurse's ASA:** rules run **once, when the patient sends the HQ** (Rahul saw no need to run them again when a nurse saves a grade).
4. **Testing rules: whole-HQ test cases** (not the recommendation): separate test cases for the whole questionnaire, checking which rules fire.
